# Fonts

Drop the hero display font here for an exact match:

- `OrangeAvenue-Regular.woff2` (or `.otf`) — used only for the hero word "Designer."

Without it, the page falls back to Playfair Display (the stand-in documented in the Figma file).
All other fonts (Inter, Playfair Display, Splash, Instrument Sans, Fraunces, Space Grotesk,
Bricolage Grotesque, Schibsted Grotesk, Geist Mono) load from Google Fonts.
